# На полку

Личные доски из фотографий, заметок, сайтов и музыкальных ссылок

## Возможности

Регистрация и вход по никнейму и паролю, без Telegram и восстановления пароля. Серверная полка приватна для аккаунта. Синхронизация видимой вкладки раз в 8 секунд и при возвращении в неё. Без регистрации данные остаются в браузере; первый вход предлагает перенести их на сервер. Черновики хранятся в IndexedDB. Одновременные изменения объединяются по полям, конфликтующие версии текста сохраняются отдельными предметами.

Миры со своей темой, цветом, фоновым фото и шрифтом. Предметы: фото, заметки, цитаты, сайты, музыкальные ссылки. Рамка, размер 80–160%, поворот, заполнение или фото целиком, показ подписи. На компьютере можно бросить до 20 фото на доску. Выборы кнопками без выпадающих списков. Мобильная сетка и свободный стол.

PNG выбранного мира с текущим фильтром, печать или PDF через окно печати; JSON для редактируемой резервной копии. PNG создаёт отдельный Canvas-рендерер: положение, содержание, цвет и размер сохраняются, небольшие отличия теней и типографики от HTML возможны. Внешние картинки должны разрешать CORS, иначе приложение попросит загрузить фото с устройства. GIF с устройства сохраняет первый кадр. Музыка открывается на сайте источника.

## Разработка

Статический предпросмотр: `npm start`, http://127.0.0.1:4185. Для API: Python 3.10+, `pip install -r requirements.txt`, Linux `gunicorn --bind 127.0.0.1:8195 'api:create_app()'`. Caddy направляет `/api/*` в API. Переменные: `POLKA_DATABASE`, `POLKA_ORIGIN`. Node-сервер служит только для статического предпросмотра.

Проверки: `npm run check`, `python -m unittest test_api -v`. Покрыты пароль, CSRF, приватность, сохранение, конкурентные записи, настройки и объединение изменений.

## Данные

SQLite: `/opt/polka/data/polka.sqlite3`. Пароли: scrypt с индивидуальной солью. Сессии: HttpOnly Secure SameSite cookie. Лимиты: 20 МБ на полку, 100 миров, 2000 предметов. Фото уменьшаются до 1400 пикселей и хранятся внутри документа. Локальный кэш остаётся на устройстве после выхода; на общем устройстве следует очистить данные сайта. Восстановления пароля нет.

Резервные копии: `/opt/polka/backups`, ежедневно, последние 14 файлов. В базе сохраняются последние 20 версий полки.

## Публикация

Исходники: https://github.com/MerlinRus/Polka
Сайт: https://polka.maark.ru

`deploy/upgrade.sh` принимает `/opt/polka/polka-source.tar.gz`. Исходники: `/opt/polka/releases/<release>` с симлинком `/opt/polka/current`. Статика: `/opt/after-rain/site/polka/releases/<release>` с симлинком `current`. API: systemd `polka-api`, пользователь polka, порт `127.0.0.1:8195`. Изменяется только блок Polka в Caddyfile; перед этим сохраняется копия и проверяется конфигурация.

Для отката переключить оба симлинка на предыдущий релиз и перезапустить `polka-api`. Базу данных не заменять. Старый `deploy/publish.sh` оставлен для первоначальной статической версии; использовать `upgrade.sh`.

Диагностика: `systemctl status polka-api`, `journalctl -u polka-api`, `curl https://polka.maark.ru/api/healthz`. Базы, секреты, виртуальная среда, архивы и скриншоты исключены из Git.
